# سنة تالتة — الترم الأول
مشروع الموقع هدفه في الاساس تسهيل الوصول لاي معلومة تخص الكلية باكتر طريقة بسيطة ممكنة , صفحة static من غير تقعيد , مهم فيها انها تكون مكان مجمع كل الي محتاجه عن القسم و يساعدك تتابع مذاكرتك في الجامعة و تنظمها احسن و تكون ايسر ليك , و اكيد الفكرة قابلة للتطوير اكتر من كدا بكتير ....

- بلا خادم، بلا قاعدة بيانات، بلا اعتماديات (npm install غير مطلوب).
- البيانات كلها في ملف واحد: `data/subjects.json`.

## 2) بنية المشروع -- مع التطورات السابقة أصبحت بنية المشروع الفعلية تشمل المكونات الإضافية التالية بجانب الملفات الأساسية المذكورة في قسم (2):


```

site/
├─ wrangler.jsonc           ← إعدادات نشر Cloudflare Workers Static Assets (fcis-is-hub)
├─ .assetsignore            ← استبعاد الملفات غير المنشورة من أصول Cloudflare
├─ CONTRIBUTING.md / LICENSE / SECURITY.md
├─ .github/
│  ├─ CODEOWNERS & ISSUE_TEMPLATE/ & PULL_REQUEST_TEMPLATE.md

├─ assets/
│  ├─ app.js                ← الواجهة، الرئيسية المخصصة، عارض PDF.js وMarkdown، التبويبات
│  ├─ pomodoro.js           ← مؤقت التركيز بومودورو ومزامنته مع المذاكرة
│  ├─ quiz.js / qr.js       ← نظام الاختبارات، الإحصائيات، والمزامنة عبر QR/JSON
│  ├─ data.js               ← النسخة المضمّنة المولدة من subjects.json وschedule.json والأسئلة
│  ├─ styles.css / logo.png / favicon.svg
│  ├─ fonts/                ← خطوط Thmanyah Serif المحلية (.woff2)

│  └─ questions/*.json      ← بنوك أسئلة كل مادة
```

### حدود يجب معرفتها

- **الخطة المجانية = مستودع Public.** أي شخص لديه الرابط يرى الملفات. `robots.txt`
  و`noindex` يمنعان محركات البحث فقط، وليس الوصول المباشر. لو ده غير مقبول قانونيًا،
  الحل هو استضافة مع حماية (Cloudflare Pages + Access) أو مستودع خاص بخطة مدفوعة.
- **GitHub Pages لا يستقبل رفع ملفات من الواجهة.** الرفع = Commit في المستودع (قسم 3).
- الملف الواحد يجب أن يكون أقل من 100MB، وإجمالي الموقع أقل من 1GB.
- نطاق ترددي مجاني ~100GB/شهر: تحميل `all.zip` مرة واحدة ≈ 173MB.
