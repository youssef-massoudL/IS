# Contributing / المساهمة في المشروع

Welcome! This project organizes lectures, summaries, schedules, and practice quizzes for 3rd-year Information Systems (IS) students. Students at the college are encouraged to contribute materials, corrections, and improvements.

مرحبًا بكم! يهدف هذا المشروع لمساعدة طلاب الفرقة الثالثة (قسم نظم المعلومات) في تنظيم المحاضرات والملخصات والجداول وبنوك الأسئلة. نرحب بمساهمات الجميع سواء بإضافة ملفات أو تصحيح أسئلة أو تحسين الكود.

---

## Governance & Decision-Making / الإدارة واتخاذ القرار

- **Maintainer Model:** This repository uses a maintainer-reviewed **Fork & Pull Request** workflow.
- **Final Review Authority:** Project maintainers (`@youssef-massoudL` and designated code owners in [`.github/CODEOWNERS`](.github/CODEOWNERS)) review and approve all changes before they merge to `main`.
- **Discuss Big Changes First:** For small fixes (typos, missing files, quiz answer corrections, small CSS/JS bug fixes), open a Pull Request directly. For new features, redesigns, or structural changes, **open a Feature Proposal Issue first** so we agree on the design before you spend time coding.

---

## Ways to Contribute / طرق المساهمة

### 1. Without Git (No Coding Required)
Open an **Issue** using our templates:
- **Request Material:** Send a link or details for a missing lecture, summary, or YouTube playlist.
- **Report a Bug:** Flag a wrong quiz answer, broken PDF, or schedule mismatch.

### 2. Via Fork & Pull Request
1. **Fork** the repository to your GitHub account and create a new branch (e.g. `add-networks-lec-07`).
2. Make your changes:
   - **Adding study files:** Put the file under `files/<subject>/<section>/`, register it in `data/subjects.json` (or use `node scripts/add-file.mjs`), then run:
     ```powershell
     node scripts/build.mjs --fix
     ```
   - **Editing schedule or questions:** Update `data/schedule.json` or `data/questions/*.json`, then run:
     ```powershell
     node scripts/build.mjs
     ```
     (`assets/data.js` is auto-generated by `build.mjs` and must stay in sync.)
3. Run the same checks CI runs before opening your PR:
   ```powershell
   node scripts/build.mjs --check
   node scripts/check-pr.mjs
   ```
4. Open a **Pull Request** targeting `main` and fill out the PR checklist.

## Rules & Guardrails / القواعد والضوابط

- **File Sizes:** Keep individual files in `files/` under **25 MiB** (Cloudflare Workers' per-file static asset limit; compress large scanned PDFs before uploading). Total site size must stay well below GitHub Pages' 1 GB limit.
- **Valid URLs Only:** Any `youtube`, `url`, or `href` values in JSON files must use `https://` or `http://`.
- **No Sensitive Data or Secrets:** Never commit `.env` files, API tokens, student IDs, phone numbers, or private personal data.
- **Copyright Notice:** While the website source code and scripts are licensed under the [MIT License](LICENSE), third-party lecture slides, books, and exam files remain the property of their respective authors/instructors. Do not upload commercial textbooks or unauthorized paid materials.
- **Restricted Paths:** Changes to `.github/workflows/`, `bot/`, `scripts/`, `index.html`, and `assets/` receive strict security review by maintainers. Keep content PRs focused on `files/` and `data/`.
